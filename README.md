📘 Sistema de Registro, Login e Painel Administrativo

Desenvolvi um sistema completo de autenticação, incluindo cadastro, login e um painel administrativo que permite visualizar, gerenciar e acompanhar todos os usuários registrados.
O administrador também pode acompanhar quantidades de acessos ao site, garantindo uma gestão mais eficiente e segura.

O foco do projeto foi desenvolver uma aplicação rápida, moderna, segura e seguindo boas práticas de arquitetura tanto no front-end quanto no back-end.

🧩 Funcionalidades

✔ Sistema completo de Login e Registro

✔ Criptografia de senhas

✔ Validação de dados

✔ Painel Administrativo com listagem de usuários

✔ Contador de acessos

✔ Proteção de rotas (JWT + Middleware)

✔ API organizada em controllers, routes e middlewares

✔ Interface moderna construída com React + SCSS

✔ Build otimizado com Vite
